# DearMe 心愿与计划文案库 v1.0

> 用途：官网功能页推荐位 + App 心愿/计划空态与创建页候选
> 规模：60 条心愿（六类各 10）+ 40 条计划（五档频次各 8）
> 语言：中英对照
> 数据源：小红书公开搜索页，检索日 2026-11-20
> 语气基线：句号结尾、不用感叹号、不评判、不催促（对齐 PRODUCT-SPEC F-005 / F-009）

---

## 0. 这一版怎么用

1. **只当种子，不当任务清单。** 每条都是"可以许下的一个念头"，用户点开后才填金额、时间、里程碑；不要把它做成必须完成的清单。
2. **文案不承诺结果。** 写的是"这件事值得"，不是"你一定能做到"。做到与放下都算走完一段。
3. **推荐位不要一次全放。** 官网每类露 2 条、App 空态露 5 条、按时间轮换，其余收进"换一批"。

## 1. 采集与证据口径

- **检索方式**：`browser_use` 打开小红书搜索页，10 组关键词：心愿清单 / 愿望清单 / 年度计划 / 存钱目标 / 旅行清单 / 陪爸妈清单 / 习惯养成 / 每月计划表 / 学一门技能 / 独处治愈。
- **抓取量**：257 张笔记卡片，去重 239 条；其中标题与直链一一对齐核验通过 45 条；另逐条打开核验 3 条（E20~E22）。
- **入附录**：22 条，覆盖存钱 / 旅行 / 计划模板 / 关系 / 自我关怀 / 愿景六类主题。
- **量级口径**：只记录搜索页展示的**点赞量级**（如 3417、1.3万）；收藏数不公开、未猜测；显示"赞"（不足百）的笔记不进附录。
- **版权**：附录只保留标题、作者、直链与我们的归纳，不复制笔记正文。
- **边界**：小红书是封闭平台，样本代表"当下被讨论的心愿主题"，不代表全体用户；热度是发现信号，不是正确性证明。
